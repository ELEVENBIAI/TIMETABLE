## Zusammenfassung

Bisher konnte das System die Leistungs-Arten ("Treppenhaus reinigen", "Garten pflegen", "Müll rausstellen", "Winterdienst", ...) zwar speichern, aber niemand konnte sie über die Software anlegen oder pflegen. Das war ein Engpass: Jede neue Leistungsart hätte ein Admin direkt in der Datenbank eintragen müssen, und Robert hätte sich auf einen Techniker verlassen müssen, um z.B. "Heckenschnitt" neu einzuführen.

Wir haben die komplette Verwaltung für Leistungs-Arten in der API gebaut. Ein Administrator oder Planer kann jetzt neue Leistungsarten anlegen, mit Name, Kürzel, Kategorie (Reinigung/Garten/Müll/Winter/Wartung/Sonstiges), einer Farbe für den Wochenplan-Kalender (#RRGGBB), einer Standard-Dauer und einer optional erforderlichen Qualifikation. Das Löschen ist abgesichert: Wenn eine Leistungsart schon irgendwo (an einer Immobilie oder in einem Wochenplan) verwendet wird, blockiert die Software die Löschung mit einer klaren Fehlermeldung — damit keine Pläne durch versehentliches Aufräumen kaputtgehen.

Damit ist eine wichtige Stammdaten-Tabelle praxistauglich. Sobald das Frontend (Tabelle + Color-Picker) gebaut ist, kann Robert das alles selbst pflegen — kein Techniker mehr nötig.
